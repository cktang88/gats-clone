# Art direction

[STYLE.md](STYLE.md) is the art bible for Tinwar: toy soldiers fighting a real night op. It covers the palette, light, line, perspective, motion, effects, interface and sound. Where the game and the bible disagree, the bible wins, within what gameplay needs to stay readable.

`gold-standard.webp` was the original reference for the floor and cover layout. The bible supersedes it where they differ; in particular, damage is now chunky (pits, cutouts and rubble), not hairline cracks, and cover stands up in three-quarter view.
